# Eclipse Moth

A single 1024x1024 PNG drawn by `main.py` with nothing but the Python standard library: a moth whose wings are a total solar eclipse - near-black plates with a golden corona rim, on a deep violet sky.

```bash
mkdir -p out
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.png
```
